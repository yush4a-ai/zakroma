# Закрома

Личная база всего полезного: ссылки, рилсы, YouTube, заметки, голосовые, скриншоты.
Кидаешь в Telegram-бота — он сам делает выжимку, ставит теги и находит по смыслу.

## Запуск на Railway

1. Залей эти файлы в репозиторий на GitHub.
2. Railway → New Project → Deploy from GitHub repo → выбери репозиторий.
3. В том же проекте: **+ New → Database → PostgreSQL**.
4. В сервисе бота → **Variables** добавь:
   - `BOT_TOKEN` — токен от @BotFather
   - `GROQ_API_KEY` — бесплатный ключ с console.groq.com (текст, скриншоты, голосовые)
   - `ALLOWED_USERS` — твой Telegram ID (несколько — через запятую)
   - `DATABASE_URL` — значение `${{Postgres.DATABASE_URL}}`
   - необязательно: `LLM_BASE_URL`, `LLM_API_KEY`, `TEXT_MODEL` — другой провайдер для выжимок (например DeepSeek)
5. Railway сам перезапустит бота. Напиши ему /start.

## Как пользоваться

- Ссылка / заметка / голосовое / скриншот → сохраняется с тегами
- `? что ищешь` → поиск по смыслу
- `/last`, `/tags`, `/tag монтаж`, `/del 12`

## Память и поиск

Поиск по смыслу использует прежнюю локальную модель и совместим с уже сохранёнными
векторами. Модель работает в отдельном процессе: один экземпляр обслуживает запросы
последовательно и завершается через 30 секунд без работы. Во время импорта процесс
переиспользуется, а в простое память модели освобождается. После паузы первый поиск
может занять несколько дополнительных секунд на загрузку модели. Внешний платный
API для поиска не требуется.

Проверки: `python -m unittest discover -s tests -v`.
